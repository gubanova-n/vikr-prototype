# Прототип ВИКР v5.15

Изменения по файлу «Комментарии.docx», на основе v5.14.

- Встроены все 13 каталогов видов работ из Cats: 3 348 записей VR, названия, категории, группы и связи с 28 существующими методиками НР/СП. Новое поле в окне экспорта не добавлено, согласно уточнению пользователя.
- Исходные XML сохранены в `modules/excel/catalogs/Cats`. Для работы через обычный `index.html` данные также включены в `cost-catalog-data.js`: чтение исходной папки на диске Z: во время работы не требуется.
- Проценты НР/СП по-прежнему берутся из ранее встроенных методик NrSp. Каталоги Cats не подменяют эти проценты.
- При выгрузке Excel «Цена, руб./ед.» рассчитывается как полная стоимость с НР и СП, делённая на объём. «Цена с индексом, руб./ед.» рассчитывается аналогично по полной стоимости с индексами.
- Цены самих ресурсов остаются без начисления НР/СП. Полные суммы родителей не увеличиваются повторно.
- Для позиции ГЭСН без состава ресурсов цена за единицу тоже рассчитывается по полной стоимости. Прямые затраты такой позиции вводятся в столбце L «Стоимость, руб.», ФОТ — в M. Это исключает круговую ссылку между ценой и стоимостью; нужные ячейки сохранены доступными для ввода.

Проверено: соответствие 9 011 записей нормативов версии 5.14; контрольная выгрузка с разными индексами ресурсов; пересчёт ставок и поправок НР/СП; нулевой объём; позиция без ресурсов; сравнение выгрузки Тамбея на 13 806 строках. Объектные JSON, сохранение объектов и файлы v5.14 не изменены.
