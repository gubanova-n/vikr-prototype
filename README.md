# ВИКР — прототип v5.15

Web-прототип для работы со структурой строительного объекта, видами работ, нормативами, ресурсами и расчётами с выгрузкой в Excel.

**Статус:** в разработке. Прототип создан совместно с коллегой и продемонстрирован заказчику.

## Мой вклад

- Проработка требований, бизнес-логики и пользовательских сценариев.
- Использование AI-инструментов для генерации и доработки кода, проверка соответствия реализации требованиям.
- Функциональное, исследовательское и регрессионное тестирование, ретест исправлений.

## Возможности

- Работа со структурой объекта и составом работ.
- Поиск и фильтрация, перенос позиций между объектами.
- Работа с ГЭСН, ресурсами, объёмами и коэффициентами.
- Расчёт стоимости и трудозатрат, выгрузка в Excel.
- Чтение и сохранение объектов в локальной папке в формате JSON.

## Запуск

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. В установленном Chrome или Edge откройте `index.html`.
3. Нажмите **«Выбрать папку»** и выберите папку `Объекты` из распакованного проекта. Разрешите чтение и запись. Приложение может изменять JSON в выбранной папке; для знакомства используйте копию.
4. Выберите объект и откройте его структуру.

Если браузер ограничивает работу при открытии файла, запустите локальный HTTP-сервер из корня проекта, например при установленном Python:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://localhost:8000` в Chrome или Edge и выберите локальную папку объектов. Удалённая папка репозитория не подключается к приложению автоматически.

## Технологии

HTML, CSS, JavaScript, File System Access API, IndexedDB, localStorage, JSZip. Сборка и установка npm-зависимостей не требуются.

## Состав проекта

- `index.html`, `app.js`, `style.css` — основной интерфейс.
- `calc.js`, `quantities.js` — расчёты и объёмы.
- `object-files.js` — работа с локальными файлами объектов.
- `modules/fsnb`, `modules/coefficients` — нормативы и коэффициенты.
- `modules/prices`, `modules/excel` — цены и экспорт.
- `Объекты` — файлы объектов.
- `Что изменено v5.13.md`–`Что изменено v5.15.md` — изменения версий.

## Ограничения

Это рабочий прототип. Полный набор пользовательских сценариев не заявлен как прошедший автоматизированную проверку. Для доступа к папке требуется поддержка File System Access API; рекомендуется настольный Chrome или Edge.

Лицензионный файл JSZip сохранён в `modules/excel/vendor/JSZip-LICENSE.md`.
