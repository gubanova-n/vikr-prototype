# Модуль выгрузки v5.15

В v5.15 подключены автономные каталоги видов работ Cats (`cost-catalog-data.js`, `cost-catalogs.js`, исходные XML в `catalogs/Cats`). API `VIKR_EXCEL_COST_CATALOGS` предоставляет `catalogs`, `forMethod(methodId)`, `methodsFor(catalogId)` и `workType(methodId, vr, catalogId)`. Связь методики и каталога определяется атрибутом Catalogs из NrSp и ID из Cats; названия и группы не используются для угадывания процентов. `VIKR_EXCEL_COSTS.resolve` дополнительно возвращает метаданные `workType`. Интерфейс экспорта не расширен.

Цены K/T для ГЭСН и родительских уровней используют полные суммы R/Y, включающие НР/СП. Цены ресурсов K/T не менялись. Для ГЭСН без ресурсов L служит вводом прямой стоимости, M — ФОТ, K/T — расчётными ценами; U вычисляется из L и индекса S. Так сохраняется пересчёт без круговых ссылок. Общие итоги и нормативы остались прежними.

Модуль получает снимок objects/nodes через существующий VIKR_EXCEL.open(request) и никогда не записывает изменения в объектные JSON.

export.js отвечает за состав, трудозатраты и отображение процесса. costs.js предоставляет справочники и разрешение нормативов, а cost-sheet.js — действующий денежный расчёт и заполнение листа «Настройки». cost-data.js содержит подготовленные цены ФСНБ, основания НР/СП и 28 методик NrSp. template.js содержит автономную двухлистовую форму.

В v5.13 полностью удалена цветовая подсветка, зависящая от полноты расчёта. Сохранены исходное оформление формы и выделение ячеек для ввода данных. Расчёты не менялись.

Контракт импорта: info.nrSpMethodology — имя файла нормативов без расширения; у позиции vr или meta.vr — идентификатор вида работ. Экспорт принимает methodology и useEstimateVr. filterPreset больше не используется. info.splitForm хранит подключение и компактный каталог цен по кодам; info.estimatePricing — регион и цены исходной GSFX по номеру и полному коду позиции. Эти поля сохраняются обычной записью объектного JSON.

Проверка Vr по ранее предоставленной смете остаётся отключаемым источником для старых записей. Новая кнопка «Цены ресурсов» позволяет дополнительно прочитать регион, Vr и цены из выбранного GSFX. Неоднозначные совпадения исключаются; цена не подбирается просто по названию.

Обновление составов и расходов остаётся ответственностью оболочки. Цены — за единицу, нормативы — проценты, поправки и индексы — множители. Базисные нормы Nacl/Plan и текущие NaclCurr/PlanCurr хранятся раздельно. Маски, отличные от ФОТ, не подменяются ФОТ.

Обычный автофильтр охватывает A:AA; представления Excel удалены. Поля ставок и индексов находятся на листе «Настройки»: B5/B6 — общие ставки, B7:B9 — индексы, B10/B11 — поправки НР/СП. Индивидуальная ставка E в таблице работников приоритетнее общей. Блок текущих нормативов НР/СП с листа убран: соответствующие значения из выбранной методики используются непосредственно в формулах W/X, без ссылок на удалённую таблицу. Различие базисных и текущих нормативов сохраняется.

Цены: сплит-форма → ФСНБ → исходная смета → пусто. В сплит-форме H — готовая текущая цена; если H пуст, используются E и I (база × индекс). Индекс применяется только один раз. Индексы пользователя на листе «Настройки» — дополнительные множители. Коды разрядов с двумя и тремя цифрами нормализуются, единица ресурса проверяется.

Z — источник цены (в том числе ручная/общая/индивидуальная ставка); AA — полнота суммы, только текст без цветовой подсветки. Формулы родителей суммируют только непосредственных детей и не блокируются отсутствующей ценой. Фильтры не меняют сам состав и сумму выгрузки. Детали денежного расчёта и трудозатраты можно сворачивать группировкой столбцов.
